# Інструкції для агентів

Спільні правила для будь-якого AI-агента, що працює з цим репозиторієм. Подробиці про проєкт, токени й компоненти — у [CLAUDE.md](CLAUDE.md).

## Спілкування

- Відповідати власниці українською, просто й коротко.
- Повідомлення комітів — українською.

## Безпека

- Не пушити в `main` і не мерджити PR: пуш у `main` публікує сайт. Merge робить тільки власниця.
- Ніколи не робити force push.
- Не читати й не комітити `.env*` та інші файли з ключами.
- Не змінювати `site`, `base`, `CNAME` і workflow публікації без дозволу.

## Перед тим як віддати роботу

- `npm run build` проходить без помилок.
- Змінене перевірено в темній і світлій темі та трьома мовами (fr, en, uk).
- Контур фокусу з клавіатури видно скрізь.
