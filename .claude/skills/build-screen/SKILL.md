# Збирання екрана за макетом

Екран і макет: $ARGUMENTS

Якщо назви екрана або посилання на макет немає — спершу запитай.

## Правила

1. Збирай екран ТІЛЬКИ з наявних компонентів (src/components/) і з токенів
   системи — CSS-змінних у src/styles/global.css (див. скіл lindigo-tokens).
   Кольорів, шрифтів, радіусів поза токенами не додавай. Кожен колір перевір
   у темній і світлій темі.
2. Якщо екрану потрібен елемент, якого в системі немає (компонент, колір,
   відступ, розмір тексту), не вигадуй його: перелічи, чого бракує, і запитай мене.
3. Позиціонування, структуру й тексти бери з плану сайту docs/plan.md.
   Тексти додавай у src/i18n/ui.ts для трьох мов (fr, en, uk); якщо якоїсь
   мови в плані немає — не перекладай сам, запитай. Готові тексти не змінюй.
   Посилання будуй через localePath(). Для сторінок, яких ще немає, роби
   якорі на секції головної (наприклад, #works), щоб вони не вели на 404.
4. Картинки з макета завантаж у відповідну теку src/assets/<блок>/ та
   імпортуй через astro:assets. Логотип не чіпай.
5. Підніми превʼю (npm run dev, http://localhost:4321/, а також /en/ і /uk/),
   щоб я порівняла з макетом. Нічого не комітить і не пушити без мого дозволу.

## Зауваги

- Секції головної зараз не мають власних `id` — `id` є лише в заголовків
  (`#works-title`, `#directions-title`, `#about-title`, `#faq-title` тощо).
  Перш ніж ставити якір, перевір, що такий `id` існує; якщо ні — запитай,
  чи додати `id` секції.
- docs/plan.md — чернетка, частина текстів у ньому тільки українською.
